## 📌 Project Overview
Leveraging **3.5 years of professional experience in Human Resources**, I developed this project to address the critical issue of gender pay gaps. This audit uses statistical modeling to detect hidden biases in organizational salary structures and proposes data-driven paths to equity.

## 🚀 Technical Highlights
- **Exploratory Data Analysis (EDA):** Identified correlations between gender, experience levels, and compensation.
- **Statistical Significance Testing:** Performed T-Tests and P-Value analysis to prove if pay gaps were statistically significant or random.
- **Predictive Fair-Pay Model:** Built a regression model to calculate "Fair Market Value" for roles regardless of gender.
